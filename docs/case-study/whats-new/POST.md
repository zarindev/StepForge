## LinkedIn (attach all 15 images, in order)

**StepForge just got 13 new features — still free, open source and 100% local.**

StepForge is my QA studio for UI, API, database, email and performance testing. This release adds:

1. Manual testing in the browser — "Run manually" opens your app with the steps in a panel beside it: pass, fail,
   blocked or skip, notes, screenshots, and a recording of the whole session
2. Marked-up screenshots and bug reports — boxes, arrows, pen and text, then expected vs actual in one click
3. Visual checkpoints — pixel comparison with a red difference image; accept a change in one click
4. Any kind of web app — fake or wait for API responses, offline mode, downloads, mobile touch, clock control,
   per-environment language, time zone, location, basic auth, proxy and certificates
5. Campaigns — one click runs a test set across environments × browsers × screen sizes
6. Reusable blocks — write "Sign in" once, fix it once, every test is repaired
7. Before/after hooks — set-up and clean-up for every test, even after a failure
8. Element repository — fix a locator once and every step follows
9. Test data library — rows from tables, CSV files, SQL queries or APIs
10. Page conditions — "if the cookie banner is visible", "repeat while Load more is shown"
11. SOAP, Kafka and FTP — test the systems behind your app
12. Slack, Microsoft Teams, Mattermost, Rocket.Chat and webhook notifications
13. Network breakdown with page-weight budgets, and a run queue with priorities

Before publishing I ran a full review: 45 bugs fixed, 450 unit and integration tests and 33 end-to-end tests passing,
and the demo benchmark still catches 25 of 25 planted bugs.

Coming next: native apps — Electron desktop apps first, then Android, iOS, and Windows / macOS / Linux desktop apps.

No accounts, no cloud, no paid APIs. MIT licensed.

GitHub: https://github.com/zarindev/StepForge
